# 01 String Functions
This folder contains hands-on practice exercises focusing on fundamental Java String manipulation techniques and built-in string methods.

## Concepts Covered:
**String Concatenation**: Combining multiple string variables using the `+` operator.
**String Length**: Using the `.length()` method to count the total number of characters in a string.
**String Replacement**: Utilizing the `.replace(oldChar, newChar)` method to substitute specific characters.
**Character Lookup**: Extracting characters at specific index locations using `.charAt(index)`.
**Substrings**: Extracting parts of a string using `.substring(startIndex, endIndex)`.

## Code Explanation:
The `StringFunctions.java` file serves as a practical demonstration of how Java handles textual data, exercises various built-in utility functions of the `String` class and outputs the transformed results directly to the console.
