# 00 Variables and Data Types
  This folder contains foundational practice exercises for Java variables and primitive data types. It serves as the starting point of my Java learning journey. 

## Concepts Covered:
**String**: Storing textual data (e.g., names).
**int**: Handling whole numbers/integers (e.g., age).
**double**: Storing functional numbers or decimals (e.g., scores/grades).
**char**: Storing single characters (e.g., letter grades).
**boolean**: Handling true/false logical states.

## Code Explanation:
The `VariablesPractice.java` file demonstrates how to declare, initialize and print various data types to the console using `System.out.println()`.
