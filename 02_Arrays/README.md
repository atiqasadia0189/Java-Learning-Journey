# 02 Arrays Practice
This folder contains hands-on practice exercises for working with both single-dimensional (1D) and multi-dimensional (2D) arrays in Java, along with built-in array operations.

## Concepts Covered:
- **1D Arrays**: Declaring, initializing and accessing single-dimensional array elements (e.g., student marks).
- **Array Length**: Utilizing the `.length` property to dynamically find the total number of elements in an array.
- **2D Arrays (Matrices)**: Working with nested rows and columns to store complex data structures.
- **Array Sorting**: Using the `Arrays.sort()` utility method from `java.util.Arrays` to automatically sort array elements in ascending order.

## Code Explanation:
The `ArraysPractice.java` file demonstrates how data is indexed, retrieved and manipulated within arrays. It highlights the syntax differences between 1D and 2D arrays and shows how to use built-in Java utility class to sort data efficiently.
